# Mohammed Muneer — Cybersecurity Portfolio

A simple, responsive GitHub Pages portfolio built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` — all page content and external links
- `style.css` — all colors, typography, spacing, and responsive styling
- `script.js` — mobile menu, active navigation, scroll reveal, current year, and copy-email behavior
- `assets/` — place the resume PDF and optional images here

## Update checklist

Search `index.html` for **UPDATE HERE**. The main items are:

1. Browser title and meta description
2. Canonical URL after GitHub Pages is live
3. Professional headline and summary
4. LinkedIn, GitHub, Medium, email, and project links
5. Resume filename
6. Skills, experience, projects, courses, certifications, and education

Search `style.css` for **UPDATE HERE** to change the color palette, fonts, width, and spacing.

## Resume

Copy your current resume into the `assets` folder and name it:

```text
Mohammed-Muneer-Resume.pdf
```

Or change the resume link in `index.html`.

## Publish with GitHub Pages

1. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the root of your GitHub repository.
2. Open the repository's **Settings**.
3. Open **Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the branch containing the files, normally `main`, and choose `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

## Notes

- No framework or build process is required.
- No external font, icon, RSS, or JavaScript service is required.
- The site supports keyboard navigation and reduced-motion preferences.
- Offensive proof-of-concept repositories are not featured in the main project section because the portfolio is positioned for security engineering and defensive operations roles.
